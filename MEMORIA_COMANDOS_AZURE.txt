MEMORIA DE COMANDOS AZURE
Actividad Autónoma - Pacientes / Historial Clínico
Los valores entre < > son placeholders. No incluir secretos reales en este archivo.

1) Login y verificación
az login
az account show
az account set --subscription <SUBSCRIPTION_ID>

2) Resource Group
az group create --name rg-aa-pacientes --location eastus

3) Azure Container Registry
az acr create --resource-group rg-aa-pacientes --name <ACR_NAME> --sku Basic --admin-enabled true
az acr login --name <ACR_NAME>

4) Construir y publicar imágenes
# Opción A (con ACR Tasks):
# az acr build --registry <ACR_NAME> --image oauthjwt:v1 --file OAuthJWT/OAuthJWT/Dockerfile OAuthJWT/OAuthJWT
# az acr build --registry <ACR_NAME> --image pacientes:v1 --file Pacientes/Pacientes.Api/Dockerfile Pacientes/Pacientes.Api
# az acr build --registry <ACR_NAME> --image historialclinico:v1 --file Historial_Clinico/Historial_Clinico.Api/Dockerfile Historial_Clinico/Historial_Clinico.Api

# Opción B (Docker local + Docker push, estándar para suscripciones estudiantiles):

docker tag practica-dockercompose-pacientes-oauthjwt:latest <ACR_NAME>.azurecr.io/oauthjwt:v1

5) Azure SQL
# Nota: Si eastus no tiene cuota de aprovisionamiento de SQL, use una región permitida como centralus:
az sql server create --name <SQL_SERVER_NAME> --resource-group rg-aa-pacientes --location centralus --admin-user <SQL_ADMIN_USER> --admin-password <SQL_ADMIN_PASSWORD>
az sql server firewall-rule create --resource-group rg-aa-pacientes --server <SQL_SERVER_NAME> --name AllowAzureServices --start-ip-address 0.0.0.0 --end-ip-address 0.0.0.0
az sql db create --resource-group rg-aa-pacientes --server <SQL_SERVER_NAME> --name PacientesDB --service-objective Basic --backup-storage-redundancy Local
az sql db create --resource-group rg-aa-pacientes --server <SQL_SERVER_NAME> --name Historial_ClinicoDB --service-objective Basic --backup-storage-redundancy Local
sqlcmd -S <SQL_SERVER_NAME>.database.windows.net -d PacientesDB -U <SQL_ADMIN_USER> -P <SQL_ADMIN_PASSWORD> -i sql/azure-pacientes.sql
sqlcmd -S <SQL_SERVER_NAME>.database.windows.net -d Historial_ClinicoDB -U <SQL_ADMIN_USER> -P <SQL_ADMIN_PASSWORD> -i sql/azure-historial.sql

6) Container Apps Environment
az containerapp env create --name env-aa-pacientes --resource-group rg-aa-pacientes --location eastus

7) RabbitMQ
az containerapp create --name rabbitmq --resource-group rg-aa-pacientes --environment env-aa-pacientes --image rabbitmq:4-management --cpu 0.5 --memory 1Gi --min-replicas 1 --max-replicas 1 --ingress internal --target-port 5672 --exposed-port 5672 --transport tcp --env-vars RABBITMQ_DEFAULT_USER=<RABBITMQ_USER> RABBITMQ_DEFAULT_PASS=<RABBITMQ_PASSWORD>

Host interno de RabbitMQ para los microservicios (mismo Container Apps Environment):
  Hostname: rabbitmq
  Port: 5672
